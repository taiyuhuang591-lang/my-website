團隊專案 · 智慧照護與資料保護 PROJECT_01

ARKAI 照護系統

📌 專案方向與目標

這是一套結合院內資料保護、去識別化與雲端 AI 應用的照護輔助專案，旨在協助護理人員整理照護紀錄。由於病歷含有患者敏感個人資料，專案核心概念為：在資料離開院內環境前，先於本地端完成資料去識別化處理，再交由雲端 AI 進行分析。

👤 個人實際參與工作 (團隊專案，本人負責部分)

🛡️
本地端資料去識別化流程： 參與病患姓名、識別碼等敏感欄位之遮罩與去識別化流程實作，確保資料在離開本地前完成去識別化處理。
🔍
資料檢視與前置處理： 參與資料在送往雲端 AI 前的格式檢查與過濾邏輯，確認機敏欄位已被適當置換。
⚡
護理紀錄 AI 分析與展示串接： 參與後端 API 與護理紀錄 AI 分析服務的介接工作，協助將分析結果整理並呈現在介面上。
🐳
系統整合與問題排查： 參與 Docker Compose 多容器環境配置（後端、資料庫與 AI 服務），協助排查容器相依與雲端連線問題，並參與使用者驗收測試（UAT）。

🔧 使用技術

Python FastAPI Docker Docker Compose PostgreSQL Cloud AI 串接 資料去識別化

⚠️ 實務遇到的問題與處理方式

問題 1 容器啟動時後端過早連線資料庫導致中斷
處理方式 在 Docker Compose 中調整服務啟動設定，並在後端啟動時實作重試等待邏輯，確保資料庫初始化就緒後才建立連線。
問題 2 UAT 驗收測試期間文字格式多樣性的校驗
處理方式 針對不同照護文字輸入格式進行規則比對與檢視，逐步修正去識別化比對條件，確保欄位脫敏同時兼顧後續 AI 分析之語意。

攻防演練 · Blue Team 藍隊防禦實作 PROJECT_02

Metis ｜ 攻防演練（校務系統防護）

📌 專案方向與目標

以校園資訊系統環境為情境進行攻防演練。我擔任藍隊（防守方）成員，主要負責目標主機環境建置、後端服務設定，並協助排查系統弱點與落實基礎安全加固，在演練過程中維護服務正常運作。

👤 個人實際參與工作 (擔任藍隊成員，負責部分工作)

🖥️
目標 VM 環境建置： 在 Linux (Ubuntu) 虛擬機上安裝配置運行所需環境，包含後端服務、Nginx 與容器環境搭建。
🔍
權限設定與敏感檔案暴露防護： 清查並修正系統中未適當保護的設定檔（如 .env）與測試目錄，調整 Nginx 反向代理規則封閉存取路徑，落實檔案最小權限。
🧱
存取日誌查核與 IP 監控： 查核 Nginx 存取日誌（Access Logs），針對高頻探測與異常來源 IP 進行記錄，並透過 UFW/iptables 進行防火牆規則阻擋測試。
🔄
資料庫備份與環境整合驗證： 協助編寫 Bash 定期備份腳本執行資料庫匯出，並在測試虛擬機中進行還原操作，驗證備份可用性。

🔧 使用技術

Linux / Ubuntu Docker Nginx Python Bash Scripting UFW / iptables 日誌查核

🛡️ 實務遇到的問題與處理方式

情境 1 敏感設定檔與未授權端點暴露風險

處理方式 在 Nginx 配置中加入阻擋規則封閉敏感副檔名與內部目錄，收斂容器埠口映射僅限本機存取，並修正檔案存取權限 (chmod 600)。

驗證結果 透過外部網路工具確認該路徑回傳 403 Forbidden 或 404 Not Found，外部無法直接讀取設定內容。

情境 2 高頻探測與異常請求流量處理

處理方式 查核存取日誌找出密集異常登入請求的來源 IP，設定 UFW / iptables 阻擋特定來源連線，並在反向代理加入請求速率限制。

驗證結果 防火牆即時封鎖特定來源 IP，日誌中該來源之異常探測連線順利被阻絕。

情境 3 資料庫備份與環境復原準備

處理方式 協助撰寫定時自動化備份腳本，將資料庫導出並存放於獨立權限目錄。

驗證結果 在全新測試 VM 中執行還原程序，確認資料結構與測試紀錄均能順利匯入，驗證備份復原流程之可行性。
